# Grand Theft Auto VII Beta (Python 3D)

Открытый 3D-прототип в духе GTA, написанный на Python с использованием движка **Ursina Engine**, с авторскими текстурами, открытым миром и процедурным звуком.

## Особенности игры
* **Два больших биома:** Мегаполис *Downtown Vice* и пустыня *Mojave Desert* со скалами, кактусами и шоссе.
* **Транспорт и физика:** Детализированное авто с крутящимися колёсами, открывающейся водительской дверью (и пасхалкой), системой повреждений, дымом, взрывами и нитро-ускорением.
* **Персонажи и арсенал:** Смена 3 героев на лету, анимация ходьбы/бега, 4 вида оружия (Пистолет, Узи, Дробовик, РПГ) и процедурная генерация звуков выстрелов и сирен.
* **Геймплей:** Городской трафик, 5 звёзд розыска с полицейскими погонями, бесконечные миссии по маякам и 3 магазина с прокачкой (*Pay 'n' Spray*, *Ammu-Nation*, *Desert Turbo*).

## Управление
* **W A S D** — езда на машине / бег персонажем
* **Мышь** — вращение камеры
* **F** — выйти из машины / сесть обратно
* **ЛКМ** — стрельба
* **1, 2, 3, 4** — выбор оружия (Пистолет, Узи, Дробовик, РПГ)
* **V** — смена персонажа
* **T** — смена времени суток (День / Закат Vice City / Ночь с фарами)
* **E** — покупка в магазинах (на цветных маркерах)
* **Shift** — спринт пешком / Нитро в машине (после покупки в *Desert Turbo*)
* **Space** — прыжок пешком
* **R** — быстрый ремонт машины
* **C** — сбросить уровень розыска

## Как запустить на ПК
1. Установите Python 3.10+
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите игру:
   ```bash
   python GTA_6_pcBeta.py
   ```
